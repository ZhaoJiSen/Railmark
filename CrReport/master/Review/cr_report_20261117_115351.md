# Railmark 初始提交代码审核

## 范围

审核 macOS 桌面应用的初始源码，覆盖 MyGo 桥接、Go 与 SQLite 数据层，以及 Next.js 工作台和 Git 面板。项目使用本地审核规范。开发服务、安装包、应用数据和离线走查素材属于本地文件。

## 核对结果

- 需求、关联目录与日志在 SQLite 事务内写入。按需求 ID、版本 ID 和目录 ID 读写时使用参数绑定，交付关联由外键及联合主键约束。
- Git 历史分页基于首批读取的提交 ID 和比较基点。测试覆盖分支和比较基点移动后继续分页，以及对无效提交 ID 的拒绝。新建本地分支使用明确选定的 Git 引用。
- 抽屉放弃修改前要求确认。日志草稿按需求在运行中的应用内保留。项目列表返回会恢复筛选、位置与焦点。
- 批量 Git 状态读取失败时显示上次结果并明确标注读取失败。异常筛选可单独清除。提交详情可用键盘进入及返回。

## 已知问题

- P2。宽布局下，加载旧提交并打开详情后，提交列表可能因列宽改变导致选中行移出可视区。可在打开详情后校正提交列表内部的滚动位置。涉及 `components/workspace/git-history-pane.tsx` 与 `components/workspace/git-commits.tsx`。

- `npm --offline run check:source` 通过。最长源文件 297 行，限制 300 行。
- `npm --offline run typecheck -- --incremental false` 通过。
- `go test ./...` 通过，含 Git 分页与临时 Git 仓库测试。
